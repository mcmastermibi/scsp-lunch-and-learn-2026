## How we keep the work transparent

- Open-source tools at every step, so a new method can be tested on our data the week it is published.
- Every analysis runs as a versioned pipeline: same steps, same settings, every time.
- Every figure and table is stamped with the pipeline version, commit, parameters, input data and date.
- A version change means every downstream output is regenerated before it is used.
- Documents that leave the lab carry a provenance statement: what was checked, what was not, and what a reader would be wrong to assume.
